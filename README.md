# Kanso

Локальная канбан-доска для работы с задачами из терминала: один SQLite-файл, веб-доска на `localhost`, MCP-инструменты для агента OpenCode.

Название — от 簡素 (*kanso*, «простота»): коротко, набирается одной рукой, не конфликтует с Linear и Jira.

## Зачем

- Задачи живут в одном месте для всех проектов, а не в семи папках.
- Сессия OpenCode берёт задачу в работу через аренду: две сессии не схватят одно и то же.
- При пересечении по файлам сессии договариваются сами, тупик уходит человеку.
- Доска открывается в браузере, данные не покидают машину.

## Быстрый старт

```sh
npm test                     # тесты
node bin/kanso.js serve      # доска на http://localhost:7777
node bin/kanso.js list       # задачи в терминале
```

MCP-сервер для OpenCode запускается как `node bin/kanso.js mcp`.

## Данные

`~/.local/share/kanso/board.db` — SQLite в режиме WAL. Бэкап — копия файла.

## Структура

```
bin/        CLI-вход
src/        хранилище, конфликты, HTTP, MCP
web/        статическая доска
test/       тесты (node:test)
docs/       спецификация и решения
```

## Версия

`VERSION` — источник истины. `package.json` обязан совпадать, это проверяет тест.
