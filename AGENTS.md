# Kanso — правила проекта

## Что это

Локальный канбан с арендой задач для сессий OpenCode. Один SQLite-файл, веб-доска, MCP-инструменты. Без облака и без внешних сервисов.

## Стек

- Node.js ≥ 22.5, ESM, без сборщика.
- `node:sqlite` (`DatabaseSync`) — единственная база. Нативных зависимостей нет.
- HTTP — `node:http`, статика из `web/`.
- MCP — `@modelcontextprotocol/sdk`, транспорт stdio.
- Тесты — `node:test` + `node:assert`.

Не добавляй фреймворки, ORM, CSS-препроцессоры и сборку. Если без зависимости не обойтись — сначала спроси.

## Команды

```sh
npm test                      # весь набор
node --test test/store.test.js   # один файл
node bin/kanso.js serve       # доска, по умолчанию :7777
node bin/kanso.js mcp         # MCP-сервер (stdio)
node bin/kanso.js list        # список задач
```

## Швы для тестов

Тестируем только здесь, внутрь не лезем:

| Шов | Что ловит | Что не ловит |
|---|---|---|
| `src/store.js` — `openStore()` | атомарный захват, аренда, зависимости, статусы | HTTP, UI, доставку сообщений |
| `src/conflicts.js` — `detectConflict()`, `resolve()` | пересечение путей, лимит сообщений, эскалацию | реальную доставку в сессию |
| `src/http.js` — `createServer()` | JSON-контракт, коды, SSE | вёрстку |
| `src/mcp.js` — `createMcpServer()` | соответствие инструментов операциям хранилища | поведение агента |

UI проверяется руками в браузере: колонки, drag&drop, drawer.

## Правила данных

- `~/.local/share/kanso/board.db` — WAL, `busy_timeout` 5 с, короткие транзакции. Файл не коммитится.
- Захват задачи — один `UPDATE ... WHERE` с проверкой владельца и аренды. Никаких «проверил, потом записал».
- Аренда 15 минут, продлевается на каждом вызове инструмента. Просроченная аренда освобождает задачу.
- Переговоры: не больше двух сообщений на конфликт, вложенные переговоры запрещены, тупик → `needs_decision`.
- Время в базе — ISO 8601 UTC.

## Версия

`VERSION` — единственный источник истины. `package.json` дублирует значение, расхождение ловит `test/version.test.js`. Формат — `X.Y.Z` плюс `alpha` / `beta` / `release`, тег `vX.Y.Z`.

## Чего не делать

- Не добавлять циклы, roadmap, оценки и велосити. Это не Jira.
- Не хранить задачи в markdown-файлах: источник истины — SQLite.
- Не ходить в API OpenCode напрямую из веб-доски: только через `src/opencode-client.js`.
- Не логировать содержимое задач и токены.
