# Kanso — редизайн «Диспетчерская» (0.3.0)

Дата: 2026-11-22. Статус: согласовано с пользователем (направление A + UX-пакет 1–8).

## Цель

Радикальный редизайн веб-доски и улучшение UX для людей: инструмент должен выглядеть
как пульт управления задачами агентов, а не как очередной тёмный канбан.

## Визуальный язык

Tactical Telemetry / CRT-терминал (industrial brutalism, тёмный архетип).

- Подложка `#0a0a0a`, поверхности `#0f0f0f`–`#1a1a1a`, линии `#262626`/`#3a3a3a`.
- Текст «белый фосфор» `#eaeaea`; вторичные `#c2c2c2`, `#9a9a9a`, `#7a7a7a` (контраст ≥ 4.5).
- Единственный акцент — аварийный красный `#ff2a2a`. Терминальный зелёный `#4af626`
  используется ровно в одном месте: индикатор активной аренды.
- Скругления запрещены (radius 0). Видимая compartmentalization: рамки 1px,
  разделители колонк через `grid gap: 1px` на фоне линии.
- Типографика: Geist Mono доминирует (метаданные, навигация, кнопки, заголовки колонк,
  uppercase, tracking 0.08–0.12em, 10–11px). Geist Sans — заголовки задач и body.
  Макро-типографика: бренд и пустая доска — Geist 800 uppercase, clamp(), leading ≤ 0.95.
- Текстуры: CRT-сканлайны и SVG-зерно — фиксированные overlay, pointer-events: none.
  Тени жёсткие offset (без blur), только у ghost и диалогов. Backdrop без blur.
- ASCII-фрейминг: `[ + ]`, `×`, `≡`, `→`, `✓`, промпт `>` в поиске. Иконки-SVG убраны.
- Hazard-полосы (45deg красный/прозрачный) — семантически: просроченная аренда,
  needs_decision, колонка «Отменено».
- Статусные квадраты колонок: контурные; «В работе» — залит красным с пульсом;
  «Готово» — залит серым. Цвета проектов/меток остаются (функциональное кодирование).
- z-index шкала: drop 40, toast 50, overlay 60, ghost 1000.
- Анимации: transform/opacity, 160–380ms, ступенчатый blink аренды;
  всё отключается при prefers-reduced-motion. View transitions и moveBefore сохранены.

## Сохраняется

IA (сайдбар + колонки + drawer), все тестовые швы, i18n RU/EN с паритетом ключей,
drag&drop с ghost и Alt+стрелками, SSE, closedby=any + fallback, карта карточек с сохранением фокуса.

## UX-пакет

1. **Командная палитра** `Ctrl/Cmd+K`: создание задачи, переход к проекту, фильтры
   (метка, приоритет, аренда), сортировка, плотность, язык, справка, сброс фильтров.
   dialog + listbox, стрелки/Enter/Esc, aria-activedescendant. Кнопка «Меню» в тулбаре.
2. **Фильтры и сортировка**: тулбар над доской — selects метка/приоритет, тумблер
   «В аренде», select сортировки (вручную/приоритет/обновлённые/созданные), «Сброс».
   Сортировка и плотность сохраняются в localStorage. Клик по метке на карточке = фильтр.
3. **Горячие клавиши**: `/` поиск, `N`/`C` новая задача, `?` справка, `Ctrl+K` палитра,
   стрелки — последовательный фокус по карточкам, `Enter` drawer, `1–5` статус фокусной карточки,
   `Alt`+стрелки — перенос (существует). Диалог-шпаргалка.
4. **Аренда как телеметрия**: на карточке зелёный квадрат + обратный отсчёт `T-ММ:СС`
   (тик 1с), просрочка — красный + hazard. В drawer — владелец, отсчёт, файлы.
5. **Онбординг**: пустая доска — макро-заголовок, CTA, CLI-подсказка, строка хоткеев;
   пустые колонки — осмысленные подсказки; справка по `?`.
6. **Инлайн-редактирование**: dblclick по заголовку карточки (и drawer) → input,
   Enter/blur сохраняет PATCH, Esc отмена. Приоритет — native select прямо на карточке.
   В drawer — select приоритета и тумблеры меток (PATCH).
7. **Тосты + undo**: кнопка «Отменить задачу» в drawer → canceled + тост с «Вернуть»
   (move обратно). Ошибки — inline-тосты, без alert.
8. **Плотность**: тумблер COMPACT/COMFORT в тулбаре, класс на body, persist.

## Границы

Без зависимостей, сборщика и фреймворков. Бэкенд не меняется (PATCH уже поддерживает
title/body/priority/labels/branch; DELETE запрещён, отмена = статус canceled).
Новые строки — только в web/locales/{ru,en}.json с одинаковым набором ключей.

## Приёмка

- `npm test` зелёный (включая паритет ключей и версию).
- Браузер: палитра, фильтры, сортировка, хоткеи, отсчёт аренды, инлайн-правка,
  undo отмены, плотность, RU/EN, drag&drop, мобильная раскладка, reduced-motion.
- Контраст текста ≥ 4.5:1, фокус-ринги видимы, скруглений нет, акцент один.
- semgrep без находок. Документация и CHANGELOG обновлены.
