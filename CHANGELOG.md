# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии по SemVer со стадиями `alpha` / `beta` / `release`.

## [Unreleased]

### Added

- Настоящее удаление задачи: кнопка «Удалить навсегда» в drawer с диалогом подтверждения, команда палитры, CLI `kanso delete <id> --yes` (без флага отказывает). Комментарии и треды удаляются вместе с задачей; ссылки `blocked_by` у других задач чистятся, полностью разблокированный backlog переезжает в todo. SSE-событие `task.deleted`; drawer удалённой задачи закрывается во всех вкладках.
- Редактор зависимостей в drawer: секция «Блокировки» с чипами текущих блокировок (убрать крестиком) и поиском задач по id/названию. Store отклоняет self-reference и циклы (код `cycle`, HTTP 400) при создании и правке; `blocked_by` нормализуется — дубликаты и пробелы убираются.
- Спека пакета v0.4: `docs/v0.4.md` и `docs/v0.4.en.md`.

### Changed

- `DELETE /api/tasks/:id` больше не отвечает 405 `use_canceled_status`: теперь 200 `{ ok, id }`, 404 `not_found`, 409 `leased` (чужая активная аренда защищает задачу от удаления).

### Fixed

- Параллельный старт двух процессов доски больше не падает с «database is locked»: `busy_timeout` выставляется до `journal_mode = WAL`. Из-за этой гонки мог молча умирать автостарт доски TUI-плагином OpenCode.

## [0.3.0-alpha.1] — 2026-11-22

### Added

- Командная палитра `Ctrl/Cmd+K`: создание задачи, поиск, переход к проекту, фильтр по метке, сортировка, плотность, язык, сброс фильтров; dialog + listbox с `aria-activedescendant`.
- Тулбар над доской: фильтры по метке и приоритету, тумблер «В аренде», сортировка (вручную / приоритет / обновление / создание), плотность COMPACT/COMFORT, кнопки «Меню» и справки. Сортировка и плотность сохраняются в `localStorage`.
- Хоткеи: `/` поиск, `C`/`N` новая задача, `?` шпаргалка, стрелки — фокус по карточкам, `Enter` — drawer, `1–5` — статус карточки в фокусе.
- Телеметрия аренды: обратный отсчёт `T-ММ:СС` на карточке и в drawer с тиком раз в секунду, просрочка — hazard-полосы; в drawer владелец и затронутые файлы.
- Инлайн-редактирование: двойной клик по заголовку карточки или drawer, select приоритета на карточке, тумблеры меток и приоритет в drawer.
- Отмена задачи из drawer с тостом и undo (возврат в предыдущий статус); у тоста кнопка закрытия, авто-скрытие откладывается пока фокус внутри.
- Онбординг: пустая доска с макро-заголовком, CTA, CLI-подсказкой и строкой хоткеев; осмысленные пустые состояния колонок.
- Спека редизайна `docs/redesign.md` и `docs/redesign.en.md`.

### Changed

- Редизайн «Диспетчерская»: CRT-терминал вместо Linear-like. Нулевые скругления, рамки 1px, моно-типографика Geist Mono, единственный красный акцент `#ff2a2a`, зелёный фосфор только у аренды, сканлайны и зерно, жёсткие offset-тени, ASCII-глифы вместо SVG-иконок.
- Клик по метке на карточке ставит фильтр по ней; одиночный клик по карточке открывает drawer с задержкой 250 мс, чтобы dblclick успевал начать переименование.
- Версия в сайдбаре показывается как `REV X.Y.Z`.

### Fixed

- Стрелки и `1–5` снова двигают фокус и статус: селектор карточек учитывает вложенность `.column-list`.
- Смена языка не сбрасывает статус соединения на «подключение».
- Инлайн-переименование карточки не открывает drawer под инпутом.

## [0.2.0-alpha.1] — 2026-11-22

### Added

- CLI для агента: `new`, `list`, `get`, `claim`, `touch`, `move`, `comment`, `release`, `done`, `threads`, `reply`, `whoami`, `serve`.
- Хранилище на `node:sqlite`: задачи, атомарный захват, аренда 15 минут, зависимости, комментарии, треды переговоров, сессии.
- HTTP-контракт и SSE: доска, задачи, захваты, треды, `/health`, коды `400/404/409/423`.
- Живое обновление доски при изменениях из других процессов через `PRAGMA data_version`.
- Веб-доска в стиле Linear: пять колонок, «Отменено» при наличии, drag&drop мышью и `Alt` + стрелки, drawer с комментариями и тредами, фильтры по проекту и поиск, SSE-подключение и тосты.
- Переговоры при пересечении путей: лимит два сообщения на сторону, решения `take-now` / `wait` / `split` / `escalate`, эскалация в `needs_decision`.
- TUI-плагин автозапуска доски и подключение в `~/.config/opencode/cli.json`.
- Тесты `node:test`: хранилище, захват, аренда, конфликты, переговоры, HTTP/SSE, версия.
- Сайдбар вместо верхней панели: бренд, «Новая задача», поиск, проекты, статус подключения, версия и выбор языка.
- Приоритеты `p0–p4` с названиями от «Критический» до «Когда-нибудь», валидация диапазона в хранилище, CLI и HTTP.
- Глобальный реестр меток с цветами: `GET/POST /api/labels`, выбор кликом при создании задачи, создание новой метки из формы.
- Git-проекты и ветки: сканирование `KANSO_ROOTS`, `/api/projects`, текущая и локальные ветки, поле `branch` у задачи, `--branch` в CLI и `--roots` у `serve`.
- Локализация RU/EN: общие словари `web/locales/*.json` для веб-доски и CLI, переключатель языка в сайдбаре, определение языка из окружения, fallback `ru`.
- Английские версии документации: `README.en.md` и `docs/spec.en.md`.

### Changed

- Интерфейс агента — CLI, а не MCP: идентичность сессии берётся из `OPENCODE_SESSION_ID`.
- Шрифты Geist и Geist Mono хранятся локально в `web/fonts/`.
- Проект в форме создания выбирается из найденных репозиториев, ветка — из веток проекта; ручной ввод остался для новых проектов и веток.
- Горизонтальная прокрутка доски работает колесиком мыши, `Shift` + колесико.
- Нативные `select` и `option` принудительно тёмные, список читается на тёмной теме.

### Fixed

- Карточки и колонки не пересобираются без необходимости; фокус фильтров и каретка поиска сохраняются.
- Клик по любой части карточки открывает задачу; перемещение не открывает drawer.
- Drag&drop: карточка следует за курсором отдельным слоем, исходная остаётся приглушённой, счётчики и «Перетащите задачу сюда» обновляются из состояния.
- `Alt` + стрелки больше не теряют фокус: карточка переезжает между колонками, а не пересоздаётся.
- SVG `+` в заголовке колонки отцентрирован.
- Пустые поля «Новый проект» и «Другая ветка» скрыты, пока не выбран соответствующий пункт.
