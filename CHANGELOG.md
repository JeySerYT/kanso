# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии по SemVer со стадиями `alpha` / `beta` / `release`.

## [Unreleased]

### Added

- CLI для агента: `new`, `list`, `get`, `claim`, `touch`, `move`, `comment`, `release`, `done`, `threads`, `reply`, `whoami`, `serve`.
- Хранилище на `node:sqlite`: задачи, атомарный захват, аренда 15 минут, зависимости, комментарии, треды переговоров, сессии.
- HTTP-контракт и SSE: доска, задачи, захваты, треды, `/health`, коды `400/404/409/423`.
- Живое обновление доски при изменениях из других процессов через `PRAGMA data_version`.
- Веб-доска в стиле Linear: пять колонок, «Отменено» при наличии, drag&drop мышью и `Alt` + стрелки, drawer с комментариями и тредами, фильтры по проекту и поиск, SSE-подключение и тосты.
- Переговоры при пересечении путей: лимит два сообщения на сторону, решения `take-now` / `wait` / `split` / `escalate`, эскалация в `needs_decision`.
- TUI-плагин автозапуска доски и подключение в `~/.config/opencode/cli.json`.
- Тесты `node:test`: хранилище, захват, аренда, конфликты, переговоры, HTTP/SSE, версия.

### Changed

- Интерфейс агента — CLI, а не MCP: идентичность сессии берётся из `OPENCODE_SESSION_ID`.
- Шрифты Geist и Geist Mono хранятся локально в `web/fonts/`.

### Fixed

- Карточки и колонки не пересобираются без необходимости; фокус фильтров и каретка поиска сохраняются.
- Клик по любой части карточки открывает задачу; перемещение не открывает drawer.

## [0.1.0-alpha.1] — 2026-11-21

- Каркас репозитория: структура, правила проекта, источник версии.
- Спецификация доски и протокола координации сессий в `docs/spec.md`.
